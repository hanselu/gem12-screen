# 屏幕公共接口与复用约定

对外入口为 `from gem12_screen import Screen, ScreenError`。其他项目只需准备图片并调用这个入口，设备查找、USB 串口协议、RGB565 编码和差分刷新由库内部处理。

## 接口

| 接口 | 用途与约定 |
|---|---|
| `Screen.connect(port=None, *, wake=True)` | 查找目标屏幕并打开连接；默认点亮并核对开屏响应。指定端口仍校验目标设备 VID/PID。失败抛出 `ScreenError`。 |
| `screen.show(source, *, force_full=False)` | 接收图片路径（字符串或 Path）或 Pillow Image，内部适配屏幕尺寸。默认差分刷新；可强制整帧。返回发送的数据块数，`0` 表示没有图像块变化。 |
| `screen.wake()` | 点亮屏幕并核对响应。 |
| `screen.turn_off()` | 熄灭屏幕并核对响应。 |
| `screen.close()` | 释放串口，不改变屏幕画面。可重复调用。 |
| `screen.port` | 实际连接的串口名称。 |
| `screen.is_connected` | 当前串口是否仍打开，不等于已探测硬件健康状态。 |

建议使用上下文管理，退出时自动关闭串口。调用方负责绘制完整图片和安排刷新频率，同一连接应顺序调用；库不自动重试失败操作。

```python
from gem12_screen import Screen, ScreenError

try:
    with Screen.connect() as screen:
        screen.show("picture.jpg")
except ScreenError as exc:
    print(f"屏幕操作失败：{exc}")
```

关屏时可以 `Screen.connect(wake=False)`，避免先点亮。动态仪表应在同一个连接里发送更新，并重新生成完整画面以清除旧文字或图形。

## 兼容性边界

- 调用方不依赖 `_protocol`、`_serial`、缓存字段、命令字、分块大小或内部函数；这些实现细节可以调整。
- 保持公开入口、方法参数和已记录行为的兼容性。未来如需不兼容修改，应提升主版本并提供迁移说明。
- 库要求 Python 3.12 及以上；代码不使用 Windows 专用接口，当前硬件验证仅覆盖 Windows。Linux/macOS 仍需实际验证串口驱动、权限和参数支持。
- 发行包只包含屏控。`gem12_touch` 暂为仓库内的独立实验代码，不属于此公共接口或正式安装包。
